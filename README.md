# Goonj

An India-first **hybrid creator platform** — a working, clickable prototype.

Blends the best of YouTube (long video + discovery), Instagram (shorts),
Twitch (live + interactive chat) and Patreon (fan clubs) into one creator-first
product. Not a clone.

## Signature hooks
- AI dubbing in the creator's own voice (22 Indian languages)
- Instant monetisation + daily UPI payouts, 90% creator split
- AI Clip Factory (one stream -> 10 shorts)
- Regional-first discovery + fan-club economy

## Run
Open `index.html` in any browser. No build step, no dependencies.

_Prototype: all data is illustrative._
